# S1.3 Plan: Escalation on breach

**Size:** S | **Complexity:** Simple (design skipped) | **Date:** 2026-08-03

## Design decision

Budget re-check happens only on `status === 'completed'` (not `'failed'`)
— the story scenarios are about a completed request's realized cost
pushing a scope over budget; a failed request's cost is a different
concern not in this story's scope. Checks the same 4 scope dimensions as
S1.2, via `spendCheck.checkBudget()` (frozen contract from S1.1) — first
breach found (any scope) triggers one incident, doesn't fire once per
scope dimension.
