# Story: Budget line on Telemetry chart (SHOULD)

## User Story
As a governance admin,
I want to see a budget's limit as a reference line on the existing cost trend chart,
so that I can see spend approaching a limit visually, without cross-referencing the admin page separately.

## Acceptance Criteria

### Scenario: active budget shows as a reference line on the cost chart
```gherkin
Given an active budget with limit_usd = 100
When I view Telemetry -> "AI cost & tokens" tab
Then the estimated_cost_usd chart shows a dashed horizontal line at y=100, labeled with the budget's scope
```

### Scenario: no active budgets — chart unchanged
```gherkin
Given no active budgets exist
When I view the same chart
Then it renders exactly as it did before this story (no reference lines, no errors)
```

### Scenario: reference lines only on the cost chart, not token charts
```gherkin
Given an active budget
When I view the input_tokens or output_tokens charts (same tab)
Then no reference line appears there — limit_usd is a dollar figure, not a token count
```

## Notes

Deliberately lightweight — reuses `budgets.list()` (S1.4) and Recharts'
`ReferenceLine`, no new backend endpoint. Multiple active budgets each get
their own line; no attempt to disambiguate which chart "series" (service
line) a scope-specific budget applies to — out of scope for this SHOULD
story, per epic scope.md's original framing.
